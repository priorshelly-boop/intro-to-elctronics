## עמוד 3 — שאלה 3 (שנאי): הצבת משוואות
- נתון: $n=\frac{n_1}{n_2}$ ; $Z_s=R_s+jX_s$ ; $Z_L=R_L+jX_L$ ; מקור סינוסואידלי $V_s$
- שרטוט: מעגל ① — מקור $V_s$ בטור ל-$Z_s$ ולסליל ראשוני ($n_1$ , מתח $V_1$) ; מעגל ② — סליל משני ($n_2$ , מתח $V_2$) מחובר ל-$Z_L$ `[שרטוט]`
- (א) "הספק ממוצע על $Z_L$:" משוואות השנאי: $\frac{V_1}{V_2}=\frac{n_1}{n_2}=-\frac{I_2}{I_1}$
- ①: KVL: $V_s=V_{Z_s}+V_1$ ; KCL: $I_{Z_s}=I_1$
- ②: KVL: $V_2=V_{Z_L}$ ; KCL: $I_2=-I_{Z_L}$
- "במעגל: $\hat V_{Z_L}=\hat I_{Z_L}\hat Z_L$ , $\hat V_{Z_s}=\hat I_{Z_s}\hat Z_s$" (פאזורים)
- $\hat V_s=\hat V_{Z_s}+\hat V_1=\hat V_{Z_s}+\hat V_2\cdot n=\hat V_{Z_s}+\hat V_{Z_L}\cdot n=\hat V_{Z_s}+\hat I_{Z_L}\hat Z_L\,n=\hat V_{Z_s}-\hat I_2\hat Z_L\,n=\hat I_{Z_s}\hat Z_s-\hat I_2\hat Z_Ln=\hat I_1\hat Z_s-\hat I_2\hat Z_Ln=-\frac1n\hat I_2\hat Z_s-\hat I_2\hat Z_Ln$

## עמוד 4 — שאלה 3 (המשך): הספק ממוצע ו-$\frac{dP}{dn}$
- $\hat V_s=\hat I_2\left(-\frac{\hat Z_s}{n}-\hat Z_L n\right)$ ; $\hat I_2=\frac{\hat V_s}{-\left(\frac{\hat Z_s}n+\hat Z_Ln\right)}=\frac{\hat V_s}{-\left(\frac{R_s}n+\frac{X_sj}n+R_Ln+jX_Ln\right)}$
- "כמו כן: $I_2=I_{Z_L}$" `[כך כתוב; לעומת $I_2=-I_{Z_L}$ בעמוד הקודם]` ; $P_{av,Z_L}=\frac12|I_{Z_L}|^2\cdot\mathrm{Re}\{Z_L\}$ ; $\mathrm{Re}\{Z_L\}=R_L$
- $|\hat I_2|=\frac{|\hat V_s|}{\sqrt{\left(\frac{R_s}n+R_Ln\right)^2+\left(\frac{X_s}n+X_Ln\right)^2}}$
- (בתיבה): $P_{av,Z_L}=\frac12|\hat V_s|^2\cdot\frac1{\left(\frac{R_s}n+R_Ln\right)^2+\left(\frac{X_s}n+X_Ln\right)^2}\cdot R_L$
- (ב) "יחס $n$ שעבורו מתקבל הספק מקסימלי: נמצא נקודת קיצון, נגזור לפי $n$ ..." `[לא קריא חלקית]` : $\frac d{dn}P_{av,Z_L}=\frac12|\hat V_s|^2R_L\cdot\frac d{dn}\left[\frac1{\frac{R_s^2}{n^2}+2R_sR_L+R_L^2n^2+\frac{X_s^2}{n^2}+2X_sX_L+X_L^2n^2}\right]$

## עמוד 5 — שאלה 3 (המשך): פתרון $\frac{dP}{dn}=0$
- $=\frac12|V_s|^2R_L\cdot\left[\frac{-\left(-\frac2{n^3}R_s^2+2nR_L^2-\frac{2X_s^2}{n^3}+2X_L^2n\right)}{\left[\left(\frac{R_s}n+R_Ln\right)^2+\left(\frac{X_s}n+X_Ln\right)^2\right]^2}\right]=0$ ; (הערות חילוק: המכנה $\ne0$ ; $-\frac12|V_s|^2R_L\ne0$)
- $0=-\frac2{n^3}R_s^2+2nR_L^2-\frac{2X_s^2}{n^3}+2X_L^2n$ ; $/:2$
- $\frac{R_s^2}{n^3}+\frac{X_s^2}{n^3}=nR_L^2+nX_L^2$ ; $\frac1{n^3}(R_s^2+X_s^2)=n(R_L^2+X_L^2)$ ; $/\cdot n^3$
- $(R_s^2+X_s^2)=n^4(R_L^2+X_L^2)$ ; $\setminus|Z_L|^2$ ; $\frac{|Z_s|^2}{|Z_L|^2}=n^4$ ; $\sqrt{\ }$ ; $\frac{|Z_s|}{|Z_L|}=n^2$
- (בתיבה): $n=\frac{\sqrt{|Z_s|}}{\sqrt{|Z_L|}}$ ; "$n\ge0$ (לא ייתכן יחס ליפוף שלילי)" `[לא קריא חלקית]`

## עמוד 6 — שאלה 3 (המשך): בדיקת סוג הקיצון
- "נבדוק סוג קיצון:" (הערה: "המכנה חיובי, ולכן נציב רק במונה:") `[כך נראה]`
- $\dot P_{av}\left(2\cdot\frac{\sqrt{|Z_s|}}{\sqrt{|Z_L|}}\right)=-\left(-\frac{2R_s^2}{\left(2\frac{\sqrt{|Z_s|}}{\sqrt{|Z_L|}}\right)^3}+2\cdot2\frac{\sqrt{|Z_s|}}{\sqrt{|Z_L|}}R_L^2-\frac{2X_s^2}{\left(2\frac{\sqrt{|Z_s|}}{\sqrt{|Z_L|}}\right)^3}+4X_L^2\frac{\sqrt{|Z_s|}}{\sqrt{|Z_L|}}\right)<0$ `[הביטוי מועתק כפי שנקרא; לא קריא חלקית]`

- (בתיבה): $n_{max}=\frac{\sqrt{|Z_s|}}{\sqrt{|Z_L|}}$

## עמוד 9 — שאלה 1 (משוואות מצב)
שרטוט: נגד $R$ וסליל $L$ וקבל $C$ בטור `[שרטוט]`
- (א) "כתבו משוואות מצבים:" $\vec x(t)=\begin{pmatrix}V_c(t)\\I_L(t)\end{pmatrix}$
- KVL: $V_R+V_L+V_C=0$ ; KCL: $I_R=I_L=I_C$ ; $q_C=V_C\cdot C$ ; $I_C=\dot V_C\cdot C$ ; $V_L=\dot I_L\cdot L$ ; "חוק אוהם:" $V_R=I_R\cdot R$
- 1) $I_L=I_C$ ; $I_L=C\dot V_c$ ; (בתיבה) $\dot V_c=\frac{I_L}C$
- 2) $V_R+V_L+V_C=0$ ; $V_C+I_LR+\dot I_LL=0$ ; $\dot I_L\cdot L=-V_C-I_LR\ /:L$ ; (בתיבה) $\dot I_L=-\frac{V_C}L-\frac{I_LR}L$
